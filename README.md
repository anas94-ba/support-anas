# Anas Baba – Support Site

Static bilingual (English / Arabic) website. English is the default language.

## Structure
- `index.html` – home with image slider
- `about.html` – who I am
- `donate.html` – how to donate (via WhatsApp intermediary)
- `documents.html` – supporting documents
- `files/` – put PDFs and other files here, then link them from `documents.html`
- `assets/img/` – logo and slider images (webp, with width/height set in HTML)

Open `index.html` in a browser or publish the folder with GitHub Pages.
